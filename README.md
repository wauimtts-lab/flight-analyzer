# flight-analyzer

# ✈️ Анализ авиарейсов

**FlightAnalyzer** — это консольное приложение на Python для **анализа авиарейсов** за выбранный период. Программа позволяет изучать задержки, сравнивать авиакомпании и определять популярные направления. Результаты анализа представлены в виде статистического отчёта.

## 🚀 Установка

Для работы приложения необходим **Python 3.10 или новее**.

1. Установите Python.
2. Скачайте репозиторий проекта.
3. Перейдите в папку проекта.
4. Установите необходимые зависимости.

### Команды установки

```bash
git clone https://github.com/user/flight-analyzer.git
cd flight-analyzer
python -m venv venv
pip install -r requirements.txt
```

> ⚠️ **Важно:** если проект использует только стандартные библиотеки Python, дополнительные зависимости устанавливать не нужно.

## 💻 Использование

Основная функция проекта — `analyze_flights()`.

### Пример вызова

```python
from flight_analyzer import analyze_flights

report = analyze_flights(
    flights=flights,
    date_from="2026-01-01",
    date_to="2026-01-31",
    airline_filter=None,
    min_delay=0,
    top_n=5,
    include_cancelled=True
)

print(report)
```

### CLI-команды

| Команда | Описание |
|---|---|
| `analyze` | Анализ авиарейсов |
| `--date-from` | Начальная дата |
| `--date-to` | Конечная дата |
| `--airline` | Фильтр по авиакомпании |
| `--min-delay` | Минимальная задержка |
| `--top-n` | Количество элементов в топе |
| `--include-cancelled` | Учитывать отменённые рейсы |

## 🏗️ Архитектура

> Приложение состоит из нескольких этапов: загрузки данных, фильтрации, анализа и формирования отчёта.
>
> Все основные вычисления выполняются функцией `analyze_flights()`.

### Схема работы

```text
Список рейсов
     |
     v
Фильтрация данных
     |
     v
Расчёт статистики
     |
     v
Формирование топов
     |
     v
Итоговый отчёт
```
